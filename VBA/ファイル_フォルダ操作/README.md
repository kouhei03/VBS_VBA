# ファイル・フォルダ操作 VBA マクロ集

Windowsのファイルシステムと連携するExcel VBAマクロです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| [Mod01_ファイル一覧.bas](./Mod01_ファイル一覧.bas) | ファイル名・更新日時・サイズ・フルパスの一覧出力 |
| [Mod02_一括リネーム.bas](./Mod02_一括リネーム.bas) | 接頭辞、文字列置換、任意の連番による一括リネーム |
| [Mod03_閉じたブック取得.bas](./Mod03_閉じたブック取得.bas) | ACE OLE DB経由で閉じたExcelブックからSELECT取得 |
| Mod81〜120 | ファイル・フォルダ操作の番号別モジュール（81〜120項目） |

追加モジュールの主な機能:

- `Mod81`〜`Mod88`: フォルダ・ファイル選択、存在確認、階層作成、一覧、再帰検索、拡張子・ファイル名抽出
- `Mod89`〜`Mod95`: コピー、移動、リネーム、削除、フォルダ操作、ファイル属性、最新ファイルオープン
- `Mod96`〜`Mod100`: 複数ブック読込、読み取り専用オープン、CSV / TSV / テキスト入出力
- `Mod101`〜`Mod108`: JSON・XML、別名保存、形式変換、ブック分割、パス解析、共有フォルダ、ファイルロック
- `Mod109`〜`Mod115`: バックアップ世代、古いファイル削除、処理ログ、リネームリスト、空フォルダ、CSV結合、テンプレート複製
- `Mod116`〜`Mod120`: 出力先オープン、ドライブ容量、ハッシュ、リンク更新制御、アーカイブ移動

## 導入方法

1. Excelで `Alt + F11` を押してVBEを開く
2. 「ファイル」→「ファイルのインポート」から、このフォルダの `.bas` ファイルをインポート
3. マクロ有効ブック（`.xlsm`）として保存

各モジュールは独立しているため、必要な機能だけをインポートできます。

## 使い方

### フォルダ内ファイルの一覧化

`フォルダ内ファイル一覧` を実行し、対象フォルダを選択します。サブフォルダを含めるかを選ぶと、「ファイル一覧」シートにファイル名、更新日時、サイズ（bytes）、フルパスが出力されます。既存の同名シートは内容を上書きします。

### 一括ファイル名変更

`ファイル名一括変更` を実行し、フォルダ、接頭辞、置換対象・置換後の文字列、連番の有無を指定します。実際に変更する前に「リネーム確認」シートへ変更前後の一覧を作り、確認ダイアログを表示します。

- 選択フォルダの直下にあるファイルが対象です（サブフォルダは処理しません）。
- 拡張子は維持します。拡張子を含む置換は行いません。
- `~$` で始まるExcel一時ファイルは対象外です。
- 既存ファイルとの衝突や変更後の名前の重複があれば、変更開始前に停止します。
- 変更中にエラーが起きた場合は、可能な範囲で元の名前への復元を試みます。念のため事前にバックアップしてください。

### 閉じたブックからデータ取得

`閉じたブックからデータ取得` を実行し、対象ブック、SELECT文、出力先セルを指定します。取得結果は出力先の1行目に列名、2行目以降にデータを書き込みます。既存セルは消去しません。

例:

```sql
SELECT [顧客名], [売上]
FROM [Sheet1$]
WHERE [売上] >= 10000
```

列名は対象シートの1行目の見出しに合わせてください。表全体を取得する場合は `SELECT * FROM [Sheet1$]` を使えます。

この方式ではExcelアプリケーションで元ブックを開きませんが、Windowsに **Microsoft Access Database Engine (ACE OLE DB Provider)** が必要です。ProviderとExcelのビット数（32/64bit）が一致している必要があります。未インストールの場合はエラーを表示します。

## 注意事項

- このマクロ集はWindows版Excel向けです。
- ファイル操作の前に、重要なデータはバックアップしてください。
- 外部ブック取得に使うSQLは読み取り専用のSELECT文にしてください。

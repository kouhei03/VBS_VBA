# データ集計・クレンジング VBA マクロ集

手作業のコピペや目視チェックをなくし、大量のデータを一瞬で整形するVBAマクロ集です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| [Mod00_共通.bas](./Mod00_共通.bas) | 共通ヘルパー（最終行取得・シート作成・フォルダ選択・高速化設定） |
| [Mod01_ファイル統合.bas](./Mod01_ファイル統合.bas) | 複数ファイル・複数シートをマスターシートへ統合 |
| [Mod02_クレンジング.bas](./Mod02_クレンジング.bas) | 表記揺れの一括修正（会社表記・全半角・スペース） |
| [Mod03_条件振り分け.bas](./Mod03_条件振り分け.bas) | 条件抽出と別シート / 別ブックへの振り分け |
| [Mod04_重複処理.bas](./Mod04_重複処理.bas) | 重複行の検出（ハイライト / 削除） |

## 導入方法

1. Excel で `Alt + F11` を押して VBE（Visual Basic Editor）を開く
2. メニュー「ファイル」→「ファイルのインポート」で上記 `.bas` を **5ファイルすべて** インポート
   （Mod00_共通 は他モジュールから参照されるため必須）
3. マクロ有効ブック（`.xlsm`）として保存

## 使い方

### 1. 複数シート・複数ファイルの統合（Mod01）

- **`複数ファイル統合`** — フォルダを選択すると、フォルダ内の全Excelファイル（全シート）を
  このブックの「マスター」シートに集約。最終列に「取込元」ファイル名を自動記録。
- **`複数シート統合`** — このブック内の全シートを「マスター」シートに集約。
- 前提: 各表は1行目がヘッダーで、列構成が共通であること。

### 2. データクレンジング（Mod02）

- **`データクレンジング実行`** — 選択範囲（未選択時はシート全体）に以下を一括適用:
  - `（株）` `㈱` → `株式会社`、`（有）` `㈲` → `有限会社` など会社表記の統一
  - 全角英数字 → 半角、半角カタカナ → 全角
  - 前後スペースの削除、全角スペース・連続スペースの圧縮

### 3. 条件抽出と振り分け（Mod03）

- **`条件別シート振り分け`** — キー列（支店・担当者など）の値ごとに別シートへ分割。
- **`条件別ブック振り分け`** — キー列の値ごとに別ブック（.xlsx）として保存先フォルダに自動保存。
- 実行時にキー列番号（A列=1, B列=2 …）を入力します。

### 4. 重複データの削除・ハイライト（Mod04）

- **`重複ハイライト`** — 重複行（2件目以降）を黄色でハイライト。
- **`重複削除`** — 重複行を削除（最初の1件は残す）。実行前に確認ダイアログあり。
- **`ハイライト解除`** — 色付けをすべて解除。
- キー列はカンマ区切りで複数指定可能（例: `1,3` → A列+C列の複合キー）。
- 判定時に表記揺れ補正（Mod02 の `CleanText`）を適用するため、
  `（株）ＡＢＣ` と `株式会社ABC` も同一とみなします。

## 注意事項

- **重複削除は元に戻せません。** 実行前にファイルのバックアップを推奨します。
- 大量データ処理中は画面更新・自動計算を停止します（処理後に自動復帰）。
- シート名に使えない文字（`: \ / ? * [ ]`）はアンダースコアに置換されます。

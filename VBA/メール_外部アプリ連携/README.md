# メール・外部アプリ連携 VBA マクロ集

Outlook、Word、PowerPoint、Access、ブラウザ、HTTP APIなどとの連携サンプルです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| Mod121〜Mod160 | 番号順に分割したメール・外部アプリ連携モジュール |

主な分類:

- Mod121〜Mod138: Outlookメール・予定表・タスク
- Mod139〜Mod142: Word連携
- Mod143〜Mod145: PowerPoint連携
- Mod146〜Mod147: Access連携
- Mod148〜Mod157: EXE、HTTP、ブラウザ、クリップボード、システム、レジストリ、タスクスケジューラ
- Mod158〜Mod160: テンプレートメール、リマインド、通知・インポート・履歴

多くのモジュールはMicrosoft Outlook、Word、PowerPoint、Accessのインストール済み環境を前提にしています。OLEオートメーションで外部アプリへ接続するため、実行時にセキュリティ確認が表示される場合があります。

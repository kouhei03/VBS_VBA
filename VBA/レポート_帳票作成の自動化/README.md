# レポート・帳票作成の自動化 VBA マクロ集

請求書、納品書、レポート、グラフ、印刷設定、PDF出力、配布用ブック生成などを自動化するVBAマクロ集です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| [Mod01_Outlook下書き.bas](./Mod01_Outlook下書き.bas) | メール送信対象と期限対象からOutlook下書きを作成 |
| [Mod02_期限アラート.bas](./Mod02_期限アラート.bas) | 期限が近い行を「期限アラート」シートに抽出 |
| Mod161〜200 | 帳票作成、書式、グラフ、印刷、配布、進捗管理、チェックリスト |

## 導入方法

1. Windows版クラシックOutlookを利用できる環境で、Excelから `Alt + F11` を押してVBEを開きます。
2. 「ファイル」→「ファイルのインポート」から、このフォルダの `.bas` をインポートします。
3. マクロ有効ブック（`.xlsm`）として保存します。
4. 下記の準備マクロを実行し、シートの見出しを作成します。

Outlook連携はWindowsのクラシックOutlook COMオートメーションを使用します。新しいOutlookでは動作しません。Outlookのプロファイルを設定し、起動・サインインできる状態にしてください。

## 1. 添付付きメールの下書き

`メール送信シートを準備` を実行すると、`メール送信` シートを作成します。2行目以降に1通ずつ入力してください。

| 列 | 内容 |
|---|---|
| A: 宛先(To) | メールアドレス。複数宛先はセミコロン区切り |
| B: 件名 | メール件名 |
| C: 本文 | メール本文 |
| D: 添付ファイルのフルパス | PDFなどのファイルパス。添付なしは空欄 |
| E: 作成対象(はい) | `はい` と入力した行だけ処理 |
| F: 結果 | マクロが作成結果を記録 |

`メール下書きを一括作成` を実行すると、対象行ごとにOutlookの下書きを保存します。添付ファイルが指定されている場合は、存在確認後に添付します。下書き保存済みの行は重複作成を避けるためスキップします。再作成する場合はF列の結果を消してから実行してください。

## 2. 期限アラートとリマインド下書き

`期限管理シートを準備` は `Mod01_Outlook下書き.bas` の準備マクロとして用意しています。実行して標準シートを作成した後、2行目以降に入力します。

| 列 | 内容 |
|---|---|
| A: タスク・契約名 | 対象の名称 |
| B: 期限 | Excelで日付として認識される値 |
| C: 担当者 | 任意 |
| D: メールアドレス | リマインド下書きの宛先 |
| E: 何日前から通知 | 期限の何日前から通知するか（0以上） |
| F: 最終下書き日 | マクロが記録 |
| G: 結果 | マクロが処理結果を記録 |

`期限アラートを表示` は期限到来済みまたは通知開始日以内の行を `期限アラート` シートへ表示します。`期限リマインド下書きを作成` は同じ条件の行からOutlook下書きを作成し、F列に作成日を記録します。同じ行から同日に重複して下書きを作成しません。

## 安全上の注意

- このマクロはメールを送信しません。送信前に宛先・本文・添付を必ず確認してください。
- Outlookの下書き保存に失敗した行は、結果列にエラーを記録します。
- 既存シートの見出しが標準構成と異なる場合は処理を停止します。
- 実データで運用する前に、コピーしたブックとテスト用の宛先で確認してください。

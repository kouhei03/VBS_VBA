## 導入方法

1. Excelで `Alt + F11` を押し、VBEを開く。
2. 「ファイル」→「ファイルのインポート」で、使用する `.bas` を読み込む。
3. 34〜36のUserForm例を使う場合は、VBEでユーザーフォームを追加し、名前を `frmBasicSample` にする。
4. フォームに `ComboBox1`、`ListBox1`、`TextBox1`、`CommandButton1` を配置する例が利用しやすい。

項目34〜36は、標準モジュールの中で `frmBasicSample` を参照します。実際のフォームを作成する場合は、フォーム側の公開プロシージャやコントロール名を用途に合わせて調整してください。
